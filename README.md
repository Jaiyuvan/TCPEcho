## TCPEcho server and client
This is a simple TCPEcho server and client system written in C++ using Socket library.
---

## Features

* **Multiple Client connection without multithread.
* **Graceful shutdown of server.
* **Non-blocking transfer of data.

## Requirements
* **Linux or any POSIX-compliant environment
* **GCC (C++ 17) or clang
* **Vscode

## Getting started
* **Clone the repository from https://github.com/Jaiyuvan/TCPEcho.git .
* **Compile the server.cpp and client.cpp.
* **Run the bash scripts.
